ระบบวิเคราะห์ท่าทางการออกกำลังกายแบบฝึกด้วยน้ำหนักและประเมินความเสี่ยงการบาดเจ็บแบบกระจายศูนย์ผ่านวิดีโอด้วยเทคนิคการเรียนรู้ของเครื่องแบบองค์รวม
FitVision: A Distributed Video-Based System for Weight Training Posture Analysis and Injury Risk Assessment Using Ensemble Machine Learning
COLLEGE OF
COMPUTING
KHON KAEN UNIVERSITY
หลักการและเหตุผล (Introduction)

การออกกำลังกายด้วยการฝึกน้ำหนัก (Weight Training) เป็นวิธีที่ได้รับความนิยมในการเสริมสร้างกล้ามเนื้อและดูแลสุขภาพ อย่างไรก็ตาม การออกกำลังกายด้วยท่าทางที่ไม่ถูกต้อง โดยเฉพาะท่าที่มีความซับซ้อน ได้แก่ Squat, Deadlift และ Bench Press อาจนำไปสู่การบาดเจ็บที่รุนแรงบริเวณหลังส่วนล่าง ข้อเข่า และข้อไหล่ในระยะยาว

ในปัจจุบัน ผู้ฝึกจำนวนมากไม่สามารถเข้าถึงเทรนเนอร์ส่วนตัวได้อย่างต่อเนื่อง โครงงานวิจัยนี้จึงได้นำเสนอ FitVision ซึ่งเป็นระบบวิเคราะห์ท่าทางแบบอัตโนมัติจากภาพวิดีโอเดี่ยว (Monocular Video) โดยประยุกต์ใช้เทคโนโลยีด้าน Computer Vision ร่วมกับ Machine Learning เพื่อประเมินความเสี่ยงและให้คำแนะนำแบบทันท่วงที (Real-time Feedback)

วัตถุประสงค์ (Objectives)
  1. พัฒนาระบบสามารถวิเคราะห์ท่าทางการออกกำลังกาย 3 ท่าหลักจำพวก (Squat, Deadlift, Bench Press) ผ่านวิดีโอโดยใช้เทคโนโลยี Computer Vision
  2. พัฒนาและเปรียบเทียบโมเดล Machine Learning เพื่อการประเมินความเสี่ยงการบาดเจ็บและวินิจฉัยข้อผิดพลาด (Error Diagnosis) ที่มีความแม่นยำสูง
  3. ออกแบบสถาปัตยกรรมระบบแบบ Edge-Cloud เพื่อให้ก้าวข้ามข้อจำกัดด้านแบนด์วิดท์ และรองรับการประมวลผลบนเซิร์ฟเวอร์ขนาดเล็กได้อย่างมีประสิทธิภาพ
ผลที่ได้รับ (Contributions)
  • ผู้ใช้งานสามารถทราบข้อผิดพลาดในท่าทางของตนเอง (เช่น เข่าบีบเข้า, หลังค่อม, ลงไม่ลึกพอ) ได้ทันทีจากวิดีโอ
  • ช่วยลดระดับความเสี่ยงในการบาดเจ็บที่อาจเกิดจากการออกกำลังกายผิดท่า
  • ได้กรอบการทำงาน (Framework) ในการสกัดฟีเจอร์เชิงเรขาคณิต (Geometric Features) ที่ใช้ทรัพยากรประมวลผลต่ำกว่าระบบ Video-CNN เดิมกว่า 80%
สรุปผล (Conclusion)

FitVision พิสูจน์ให้เห็นว่าการใช้เทคนิค Domain-Specific Feature Engineering ควบคู่ไปกับ Tree-based Ensemble Models สามารถให้ผลลัพธ์การจำแนกท่าทางที่มีความแม่นยำสูงมาก (สูงถึง 94.5% ในท่า Squat และ 90.8% ในท่า Deadlift) โดยไม่จำเป็นต้องพึ่งพาโมเดล Deep Learning ขนาดใหญ่ในส่วนของการจำแนกประเภท (Classification)

นอกจากนี้ สถาปัตยกรรม Distributed Edge-Cloud ที่ถ่ายโอนภาระการคำนวณ Landmark ไปยังเบราว์เซอร์ผู้ใช้ ช่วยแก้ปัญหาคอขวดแบนด์วิดท์และช่วยให้เซิร์ฟเวอร์ขนาด 512MB RAM สามารถให้บริการผู้ใช้งานจำนวนมากได้พร้อมกันอย่างราบรื่น

การนำไปใช้และพัฒนาต่อ (Applications & Extensions)
  • ขยายขอบเขตชนิดของการออกกำลังกายให้ครอบคลุมท่าอื่นๆ เช่น Overhead Press, Barbell Row, Lunge
  • พัฒนาและบูรณาการระบบติดตามการเคลื่อนไหวเพื่อทำ Repetition Counting (นับจำนวนครั้งอัตโนมัติ) และ การวิเคราะห์ความเร็ว (Tempo Analysis)
  • เชื่อมต่อเข้ากับแอปพลิเคชันบนมือถือพร้อมระบบ Gamification เพื่อสร้างแรงจูงใจในการออกกำลังกาย

แนวคิดและนวัตกรรมที่พัฒนา (Innovations & Technical Highlights)
⚙️ Domain-Specific Features
สกัด 33-point 3D Landmarks ด้วย MediaPipe แล้วคำนวณ Joint Angles, Distances และ Symmetry ด้วยหลักตรีโกณมิติ เฉพาะจุดที่สำคัญของแต่ละท่า (20 ฟีเจอร์สำหรับ Squat, 13 ฟีเจอร์สำหรับ Deadlift/Bench Press) ทำให้แบบจำลองมีขนาดเล็กมาก โมเดลจึงทำงานได้เร็ว
🚀 Memory-Optimized Serving
ออกแบบระบบ Lazy-loading & Aggressive Garbage Collection สลับโมเดลเข้าออก RAM อัตโนมัติเมื่อสิ้นสุดคำสั่ง ส่งผลให้สามารถนำโมเดลขนาดใหญ่หลายตัวมาให้บริการบนเซิร์ฟเวอร์ที่มี RAM จำกัดเพียง 512MB ได้อย่างเสถียร
🔀 Sophisticated ML Architecture
ปรับโครงสร้างอัลกอริทึมให้เหมาะกับตัวแปรของแต่ละท่า โดยใช้ Voting Ensemble (XGB+RF) สำหรับท่าที่ซับซ้อนอย่าง Squat รวมไปถึงการแก้ปัญหาชุดข้อมูลที่ไม่สมดุล (Class Imbalance) ด้วยเทคนิค SMOTE ในทุกโมเดล
🌐 Distributed Edge-Cloud
ประมวลผลวิดีโอและ Landmark ด้วย Web Browser (Edge) แล้วจึงส่งต่อเป็นอาเรย์อาร์กิวเมนต์ตัวเลขไปยังเซิร์ฟเวอร์บน Cloud (Backend) เพื่อทำ ML Classification ลดขนาด Data Payload จากวิดีโอระดับ MB เหลือเพียงระดับ KB

🎯 Squat: ประสิทธิภาพสูงสุด
พบว่า Voting Ensemble (XGBoost + RF) ให้ความแม่นยำสูงสุด 94.52% เหมาะสมที่สุดสำหรับการจำแนกข้อผิดพลาดแบบละเอียด (6 Classes) เพราะผสานการทำงานของกลุ่ม Boosting และ Bagging เข้าด้วยกัน
⚡ Deadlift: ลดการใช้ทรัพยากร
สำหรับท่าที่มี 2 Classes เปลี่ยนมาใช้โมเดลเดี่ยวอย่าง Random Forest (F1: 91.65%) แทนอัลกอริทึมที่ซับซ้อน เพื่อประหยัด RAM บนเชิร์ฟเวอร์ให้เหมาะสมกับขีดจำกัด 512MB
📈 Bench Press: แม่นยำสม่ำเสมอ
การใช้ Voting Ensemble (Soft Voting) ให้ผลลัพธ์ที่ยอดเยี่ยม (Accuracy 99.45%) ช่วยตัดสินและแยกแยะความถูกต้องของการยกในจังหวะการจัดวางแขนและระยะไหล่ได้อย่างเฉียบขาด
