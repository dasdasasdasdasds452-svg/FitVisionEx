Innovations & Technical Highlights (แนวคิดและนวัตกรรมที่พัฒนา)
⚙️ Domain-Specific Feature Engineering
แทนที่จะใช้ภาพต้นฉบับป้อนเข้า CNN เราสกัด 33-point 3D Landmarks ด้วย MediaPipe แล้วคำนวณ Joint Angles, Distances และ Symmetry ด้วยหลักตรีโกณมิติ ทำให้ชุดข้อมูลมีขนาดเล็กมาก โมเดลจึงทำงานได้เร็วและเบา
🚀 Memory-Optimized Model Serving
พัฒนาระบบ Lazy-loading & Aggressive Garbage Collection สลับโมเดลเข้าออก RAM อัตโนมัติ ทำให้สามารถรันโมเดล Machine Learning ขนาดใหญ่แบบ Ensemble บน Cloud Server ที่มี RAM จำกัดเพียง 512MB ได้โดยไม่เกิด OOM
🔀 Voting Ensemble Architecture
ผสานพลังระหว่าง XGBoost และ Random Forest (Soft Voting) เพื่อเพิ่มความแม่นยำ (94.5%) รวมถึงแก้ปัญหา Class Imbalance ด้วยเทคนิค SMOTE ให้เรียนรู้ท่าทางที่ผิด (Error Classes) ได้ครอบคลุมขึ้น
🌐 Distributed Edge-Cloud Inference
แยกการทำงานโดยให้ Web Browser (Edge) คำนวณรันผล MediaPipe แล้วส่งแค่ข้อมูลคณิตศาสตร์ไปหา Backend (Cloud) เพื่อทำ ML Classification ลดขนาด Data Payload จากวิดีโอหลาน MB เหลือเพียงไม่กี่ KB/frame ปลดล็อค Real-time analysis คล่องตัว

Model Evaluation Results (Squat Posture Analysis)
To validate our approach for Squat analysis, we evaluated 9 different machine learning algorithms on the extracted 20-dimensional feature set. The dataset consisted of 21,451 frames of 3D landmarks. The results show that our proposed 2-Model Voting Ensemble (XGBoost + Random Forest) achieved the highest performance across all metrics.
